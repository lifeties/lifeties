# 신청서 항목 ↔ 데모 기능 대응표

신청서(제안 모드 수정본 기준)의 각 약속이 데모 어디에 구현되어 있는지 정리했습니다.

| 신청서 항목 | 내용 | 데모 위치 |
|---|---|---|
| 4. 서비스 내용 | 하객이 모바일 청첩장·부고에서 신용카드로 축의금·조의금 결제 | `/i/{code}` · `routers/public.py` |
| 4. 서비스 내용 | 할부 최대 3개월 | `core.check_limits` (0·2·3개월만 허용) |
| 4. 서비스 내용 | 식장 계약서 첨부 → 와이즈앤코가 예약 확인 후 공개 | `/host/events/new` → `/admin/events/{id}` 식장 확인 |
| 4. 서비스 내용 | 장례는 제휴 장례식장 이용 확인으로 대체 | 장례는 계약서 없이 등록, 운영자 확인 후 공개 |
| 4. 서비스 내용 | 모바일 식권 QR, 식권 사용률로 행사 실재 확인 | 영수증의 QR · `/venue` 검표 · `low_checkin` 규칙 |
| 4. 서비스 내용 | 행사일 + [3]일 후 혼주(상주) 본인 명의 계좌로만 정산, 행사 전 인출 불가 | `core.request_settlement` · `settlement_hold_days` |
| 4. 서비스 내용 | 1원 인증으로 예금주 일치 확인, 가상계좌 미사용 | `/host/bank` |
| 4. 서비스 내용 | 감사 메시지 자동 발송 | `/host/events/{id}/thanks` |
| 4. 서비스 내용 | 법인 경조금 지급확인서 발급 | `/g/{token}/certificate` |
| 5. 업무 분담 | 결제 승인·정산은 제휴 PG, 와이즈앤코는 행사 검증·한도·이상거래 1차 감시·정산 보류 | `services/providers.py`(PG mock) · `services/core.py` |
| 11. 이용자 보호 | 정산 전 하객 직접 취소 | `/g/{token}/cancel` |
| 11. 이용자 보호 | 행사 취소 시 정산 전 결제 전액 자동 취소 + 문자 | `core.cancel_event` |
| 11. 이용자 보호 | 정산 후 반환 요청 → 혼주(상주) 동의 | `/g/{token}/return` → `/host/returns/{id}` |
| 11. 이용자 보호 | 민원 [15]일 이내 처리 | `/support` → `/admin/inquiries`(기한·초과 표시) |
| 11. 이용자 보호 | 연락처·계좌 상호 비노출, 관리자 화면 기본 마스킹, 원본 열람 시 사유 기록 | `mask_*` 필터 · `/admin/events/{id}/reveal` · 감사 로그 |
| 11. 이용자 보호 | 수집 항목 최소화(주민등록번호 미수집) | `User` 모델: 이름·생년월일·전화·CI·계좌만 |
| 12. 위험관리 | 1건 [50]만원 · 행사당 [3,000]만원 · 하객 1인 월 [200]만원 | `core.check_limits` · `/admin/settings` |
| 12. 위험관리 | 혼주(상주) 1인 연 [3]회 행사 개설 | `core.can_open_event` |
| 12. 위험관리 | 혼주 본인 카드로 자기 행사 결제 차단 | `check_limits` (CI 비교) |
| 12. 위험관리 | 제재대상자 명단 일치 시 경보 | `sanction_list` 규칙 |
| 12. 위험관리 | 같은 기기 여러 명의, 30일 내 반복 결제, 단기 반복 개설, 결제 집중, 가입 당일 고액, 식권 사용률 저조 | `core.run_rules_for_gift` · `run_rules_for_event` |
| 12. 위험관리 | 경보 시 정산 자동 보류 → 담당자 검토 → 해제 또는 FIU 보고 요청 | `/admin/alerts` · `core.review_alert` |
| 12. 위험관리 | 모든 검토·조치를 감사 로그로 보관 | `AuditLog` · `/admin/audit` |
| 13. 성과 지표 | 사용자수·거래금액 + 위험관리(경보·보류·해제율·보고) + 소비자보호(민원·처리기간·취소) | `/admin` 대시보드 |
| 16. 지정기간 종료 | 보존기간 경과 정보 파기, 파기 기록 | `/admin/settings` 파기 · `core.purge_expired` |
| 개선 사항 | 경조사 데이터 B2B 판매·국세청 제공 삭제 | 데모에 해당 기능 없음(의도적으로 제외) |
| 개선 사항 | 행사 전 조기 인출 삭제 | `FEATURE_EARLY_WITHDRAWAL = False` |

`[ ]` 안 숫자는 예시값이며 `/admin/settings`에서 바꿀 수 있습니다.
